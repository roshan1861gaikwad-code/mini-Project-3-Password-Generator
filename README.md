# 🔐 Password Generator

A beginner-friendly Python project that generates random passwords using letters, numbers, and symbols.

## Features
- Custom password length
- Uppercase and lowercase letters
- Numbers and symbols
- Input validation
- Secure random character selection

## What I Learned
- Python modules (`string`, `secrets`)
- Variables and user input
- `if/else` conditions
- `for` loops
- Lists and strings
- Exception handling (`try/except`)

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Run:

   `python password_generator.py`
